# すぐ変換ラボ 設計
ユーザーの正式着工指示（2026-11-02）を仕様正本とする。詳細設計は一任、細かな確認を省き実装・公開を実行する指示に従う。

## 採用構成
一つのGitHubリポジトリから独立したCloudflare Pages二つへ配信する。案内は `sugu-henkan-lab`、処理は `sugu-henkan-tools` を候補名とし、公開確認までURLを確定扱いしない。静的HTML/CSS/ES Modules、ビルドはNode標準機能のみ、QR依存一つをMITライセンス付きで同梱する。

同一オリジンで広告を読む案は、広告が入力DOMへ到達できるため不採用。iframe埋め込み案は境界と操作が複雑になるため初期版では不採用。別オリジンの独立したトップレベル画面を採用する。`postMessage`、URL本文共有、本文保存なし。処理側はCSP default-src none / connect-src none / frame-ancestors none / form-action none、参照元送信なし、同一オリジンのスクリプトのみ許可。広告が案内ページの遷移先を書き換えるリスクやブラウザ拡張機能まで防ぐ保証はしない。処理側をブックマークして直接利用できる。

## 機能
文字数は書記素・Unicodeコードポイント・UTF-16・UTF-8を明示。全半角はASCII英数字・記号・カナ・空白を選択。空白整理と重複行削除は設定選択、順序維持。CSV/TSVは引用符・セル内改行・BOM・式を扱い、既定で式開始文字にアポストロフィーを追加、未保護出力は明示選択。JSONは構文検証後にトークンを整形し数値と重複キーを保存。URLはcomponent方式、plusの空白扱いを選択。QRはブラウザ内生成、PNG保存・画像コピー（非対応時は説明）。連続変換は全半角→空白→重複、設定のみ任意保存。

## 画面と公開
案内トップ、各8紹介、5解説、privacy/about/contact。白と生成り、濃紺、青緑、紫の配色、大きな見出し、押しやすいボタン。処理は同じ視覚言語で広告無しを明示。入力は2MiB、QRはUTF-8で1000バイト上限。入力時の送信・自動保存なし。巨大入力は明示エラーで前回結果を破棄。
SEOはcanonical、description、OGP、WebSite/WebApplication/BreadcrumbList、sitemap/robotsを静的生成。Adsterraは案内側だけ、新規コード未取得ならなし。Search Consoleは本人認証後。運営は既存枠を保持して小さく追記。

## 検証
Nodeテストで境界・Unicode・CSVラウンドトリップ・式・JSON精度・不正入力を確認。生成物のリンク、CSP、処理側の外部依存禁止を静的検査。クラウドブラウザで実機能を操作。360/390/768/1280およびAndroid実機は実際に確認できた範囲のみ記録。Cloudflare未認証なら制作とGitHub保存を先に完了して認証を依頼する。
